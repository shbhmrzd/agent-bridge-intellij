A first useful answer in a few steps

  1. Install a supported provider CLI and Agent Bridge into a supported IntelliJ IDEA 2024.3.2.2–2026.2.x installation.
  2. Open a source file and the Agent Bridge tool window.
  3. Choose your provider from the compact model control; open the gear → Sign in.
  4. Complete the provider’s authentication flow, then ask “Explain this file and identify one edge case.”
  5. Request a specific fix and use Review changes when a supported proposal is returned.
