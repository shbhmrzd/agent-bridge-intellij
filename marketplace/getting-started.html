Start a conversation about your code

  1. Install a provider CLI. Follow the official installation instructions for Claude Code, OpenAI Codex or GitHub Copilot CLI. Check that your account supports the chosen tool.
  2. Open your project in IntelliJ IDEA 2024.3.2.2 through 2026.2.x. Open a source file, then choose View → Tool Windows → Agent Bridge.
  3. Choose a provider. Click the provider/model control at the bottom of the composer. If the CLI cannot be found, open the gear → Settings and enter its absolute executable path. In a terminal, command -v claude, command -v codex or command -v copilot can help locate it.
  4. Sign in. Open the gear → Sign in. Complete the provider’s browser or CLI authentication steps. For Codex, use the device-code alternative if the browser flow cannot complete. Return to the plugin and choose Check login for Claude or Codex; Copilot confirms sign-in in its terminal. Do not paste passwords or tokens into chat.
  5. Ask a question. Keep the current-file checkbox selected and ask “Explain this file and identify an edge case.” Press Enter to send or Shift+Enter for a new line.
  6. Add context when needed. Use + Files to select project files or folders. You can also select items in the Project pane and choose Add to Agent Bridge. The gear’s Find related project files option adds bounded, relevant context automatically.
  7. Ask about a selection. Select code in the editor and use Chat About Selection. Its conversation stays attached to the captured file and range.
  8. Review a proposed change. Request a specific fix. When Review changes appears, inspect the diff and apply the reviewed proposal. Multi-file proposals apply together. Undo is supported. If the file has changed since the request, ask for a fresh proposal.

Model availability and usage limits come from your provider account. Default uses CLI configuration. Each installer uses their own locally configured provider account; maintainer credentials are not included. Provider installation and authentication are required even if you are already signed into a separate desktop application.

If sign-in stalls, inspect the provider login terminal, complete any pending prompt and check login again. If a model is unavailable, choose Default or an account-supported model. Closing inline chat or restarting the IDE does not preserve that IDE conversation.
