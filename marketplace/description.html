AI coding chat using your existing accounts

Agent Bridge connects IntelliJ IDEA to your installed Claude Code, OpenAI Codex and GitHub Copilot CLIs. Ask questions about your current file or selected code, add project context, and review suggested changes before applying them.

Free and open source. No JetBrains AI subscription required. A supported provider account is required; provider usage limits and charges apply.

Built around asking and reading

  • Current-file context: include the open editor buffer, including unsaved changes.
  • Chat beside selected code: open a small composer from the editor selection and continue the conversation there.
  • Project context: attach files and folders through IntelliJ’s project picker, or enable a bounded search for related project files.
  • Compact model selection: choose your provider and model in one menu. Codex can load available choices from its CLI; Claude offers familiar model aliases and a custom model option.
  • Reviewable changes: inspect supported suggestions in IntelliJ’s diff view, apply the reviewed proposal, and use Undo. Multi-file proposals apply together.
  • Conversation continuity: continue with recent context or start fresh when switching provider or model.
  • Keyboard first: Enter sends; Shift+Enter inserts a new line.
  • Account controls: sign in, check login or change configuration from the settings gear.

Your CLI, your account

Install at least one supported CLI separately. Agent Bridge launches the provider’s authentication flow and uses that CLI’s account configuration. Claude and Copilot use their CLI sign-in flows; Codex offers browser sign-in and a device-code alternative. Each installation uses that user’s local CLI account or API configuration; no maintainer credentials are bundled. Provider credentials remain managed by the CLI.

No separate JetBrains AI subscription is required. Provider eligibility, subscriptions, usage limits and any API charges still apply. Installing the plugin does not grant free or unlimited model access.

Try a first question

  1. Open a project and a source file, then open the Agent Bridge tool window.
  2. Choose your provider, open the gear and sign in if needed.
  3. Ask: “Explain this file and identify one edge case.”
  4. For a change, ask for a reviewable fix. Use Review changes when a supported proposal appears, inspect the diff, then apply it.

Current scope

This preview targets IntelliJ IDEA 2024.3.2.2 through 2026.2.x (builds 243.23654.189 through 262.*). Its declared dependencies do not require Ultimate features. A working provider CLI and eligible account are required.

Automatic context uses bounded text-based retrieval; it does not upload the entire project. Provider tools may read additional project files under their own policies. Code supplied as context is processed by the selected provider according to its configuration and terms.

Suggestions currently edit existing attached text files. File creation, deletion, renaming, inline ghost-text completion and restoring IDE chat history after restart are not supported. The selected range focuses a question; review the diff to check the actual edit scope.

Agent Bridge is an independent integration, not an official OpenAI, Anthropic, GitHub or JetBrains product.
